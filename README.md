# Login Animation — olhar que segue o cursor

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

Tela de login visual: quatro personagens seguem o mouse com a pupila, olham para o e-mail quando o campo ganha foco e escondem os olhos no campo de senha. O botão é `type="button"` e não envia credencial.

## Stack

- HTML5, CSS3 e JavaScript, sem dependência e sem build

## Estrutura

```
index.html
style.css
script.js
```

## Como rodar

```bash
git clone https://github.com/gabrielteramae/login-animation.git
cd login-animation
```

Abra `index.html` no navegador.
